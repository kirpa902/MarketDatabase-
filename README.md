**Market Management System
Description**

A Java Swing and MySQL based desktop application to manage customers and their transactions. It supports adding, updating, deleting customers and tracking purchases with payment status.

**Features**
Add, update, delete customers
Manage transactions
Track payment status (cash, goods, pending)
View transaction history
MySQL database integration using JDBC
Technologies Used
Java (Swing)
JDBC
MySQL
**How to Run**
Import project in IntelliJ IDEA
Import market_db.sql into MySQL
Update database credentials in DBConnection.java
Run Main.java
